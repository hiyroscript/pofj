# Persistent branch reference

The graph combines alternate events with stateful rejoining scenes. There are fifteen two-way extended-event branch groups in `data/branches`, plus alternate midterm and mutual/unreciprocated conversations. All choices have authored immediate responses. Intermediate conversation decisions alter a meter or relationship; larger commitments also set the named route facts used below.

`docs/STORY_GRAPH.md` lists every event and outgoing target. `data/story.js` is the assembled graph and `data/memories.js` supplies additional explicit later callbacks. Availability conditions never remove the two unconditional ways forward. A refusal does not prevent academic completion.

## Ending selection and testing

Category is determined from the completed academic and relationship state, then a prioritized flag selects one of eight epilogues in that category. Broad flags may coexist with more specific ones; the explicit priority list in `pickEnding` decides which story is shown. The generated reference lists every selector.

Seven deterministic engine routes demonstrate independent/social/balanced academic success, voluntary dating from each style, and a failing assessment route. Two hundred seeded mixed-action routes test graph termination and valid state. All 24 selectors are individually tested with valid constructed states. This selector test is not a claim that all 24 distinct histories have been manually played from arrival.
