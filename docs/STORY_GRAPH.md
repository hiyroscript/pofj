# Story graph reference

Generated by `node tools/reference.js` from the shipped graph. Conditions and effects in the JavaScript data are authoritative. Entry point is `p01`; terminal is `epilogue`. Each event expands into the listed number of passages; `event~1` is its first passage when split, and the original ID is its final major decision. Intermediate decisions retain the event’s location and time. Their prose is partitioned, never duplicated.
